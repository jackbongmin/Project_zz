# Project ZZ — 기초 기획서 (GDD v0.1)

> 작성일: 2026-11-13 · 엔진: Godot 4.7.2 · 언어: **C++ (GDExtension / godot-cpp)** · 아트: 로우폴리 (Poly Pizza / Quaternius / Kenney)

---

## 1. 한 줄 요약
**방사능 낙진으로 무너진 세계에서, 폐가를 털어 보급품을 모으고 작은 은신처를 점점 거대한 거점으로 키워나가는 로우폴리 생존 게임.**

## 2. 핵심 컨셉
| 항목 | 내용 |
|---|---|
| 장르 | 오픈 필드 파밍 서바이벌 + 거점 건설/확장 |
| 시점 | **1인칭 ↔ 3인칭 전환** (V 키) |
| 그래픽 | **풀 3D 로우폴리** (2.5D 아님) — 3D 모델 + 자유 시점 카메라 |
| 아트 | 채도 낮은 황무지 + 방사능 지역은 녹색 발광 포인트 |
| 플랫폼 | PC (Windows) |
| 플레이 | 싱글 플레이 |
| 톤 | 쓸쓸하지만 희망적 — "부서진 세상에서 내 자리를 다시 만든다" |

## 3. 핵심 게임 루프
```
 ┌──────────────► 탐색 (폐가·폐차·창고)
 │                  │
 │                  ▼
 │              파밍 (식량·물·자재·약품·부품)
 │                  │
 │                  ▼
 │              생존 관리 (허기·갈증·방사능·체력)
 │                  │
 │                  ▼
 └──── 거점 복귀 ── 제작·건설·확장 ──► 더 먼 지역 탐색 가능
```
- **짧은 루프 (5~10분)**: 거점 → 근처 폐가 털기 → 귀환 → 제작
- **긴 루프 (수 시간)**: 거점 확장 → 방사능 필터/방호복 확보 → 오염도 높은 지역 진출 → 희귀 자원 → 더 큰 확장

## 4. 생존 수치
| 수치 | 감소/증가 요인 | 0 또는 최대일 때 |
|---|---|---|
| 체력 (HP) | 피격, 낙하, 굶주림, 방사능 | 0 → 사망 |
| 허기 | 시간 경과, 달리기 | 0 → 체력 지속 감소 |
| 갈증 | 시간 경과 (허기보다 빠름) | 0 → 체력 빠르게 감소 |
| 방사능 | 오염 지역 체류, 오염된 식량/물 섭취 | 최대 → 최대 체력 감소 + 체력 감소 |
| 스태미나 | 달리기, 근접 공격 | 0 → 달리기 불가 |

- 방사능은 **약품(요오드정, 해독제)** 이나 거점의 **정화 시설**로만 낮출 수 있음
- 방호복/방독면 착용 시 방사능 축적 속도 감소

## 5. 시점 시스템 (1인칭 / 3인칭) — **M0 구현 대상**
- **V 키**로 즉시 전환
- **1인칭**: 실내 파밍, 정밀 조준, 몰입감 → 폐가 내부 탐색에 유리
- **3인칭**: 넓은 시야, 건설 배치, 이동 → 야외/거점 관리에 유리
- 3인칭 카메라는 `SpringArm3D`로 벽에 파묻히지 않게 처리
- 1인칭에서는 캐릭터 몸체를 숨기고 그림자만 표시
- 상호작용(E)은 두 시점 모두 **화면 중앙 레이캐스트** 기준으로 통일

## 6. 파밍 시스템
- **파밍 대상**: 폐가의 서랍·냉장고·옷장·상자, 폐차 트렁크, 쓰레기 더미
- 상호작용(E) 홀드 → 진행바 → 루팅 창
- 각 컨테이너는 **루트 테이블**(확률표)로 랜덤 아이템 결정
- 한 번 턴 곳은 "털림" 표시, 일정 일수 후 일부만 리필 (선택)
- 지역의 **위험도/오염도**가 높을수록 보상이 좋음

### 아이템 카테고리 (초기)
| 분류 | 예시 |
|---|---|
| 식량 | 통조림, 건빵, 오염된 고기 |
| 물 | 생수, 오염된 물 (정수 필요) |
| 자재 | 나무 판자, 고철, 못, 천, 테이프 |
| 부품 | 전자 부품, 배터리, 파이프 |
| 의약품 | 붕대, 진통제, 요오드정 |
| 장비 | 쇠파이프, 손도끼, 방독면 |

## 7. 인벤토리
- 슬롯 + 무게 제한 (가방 업그레이드로 확장)
- 핫바 1~6
- 거점에 **보관함** 설치 → 공용 창고

## 8. 거점 (터전) 시스템 — 이 게임의 핵심
### 8-1. 단계별 확장
| 단계 | 이름 | 해금 요소 |
|---|---|---|
| 1 | 캠프 | 모닥불, 침낭, 작업대(기초), 보관함 |
| 2 | 은신처 | 벽/바닥/문, 빗물 수집기, 텃밭 |
| 3 | 요새 | 바리케이드, 발전기, 조명, 정수기 |
| 4 | 정착지 | 방사능 정화기, 생존자 NPC 합류, 자동 생산 |

### 8-2. 건설 방식
- 3인칭에서 건설 모드(B) → 반투명 미리보기 → 그리드 스냅 배치 → 자재 소모
- 구조물에는 내구도가 있고 수리 가능

### 8-3. 거점의 역할
- **안전지대**: 방사능 0, 휴식하면 체력 회복
- **생산**: 텃밭(식량), 빗물 수집(물), 발전기(전력)
- **확장 동기**: 더 좋은 시설 → 더 먼 지역 진출 가능

## 9. 월드
- 초기: **작은 교외 마을 1개** (폐가 6~10채, 주유소, 슈퍼)
- 구역별 오염도: 🟢 안전 / 🟡 경미 / 🔴 고오염 (방독면 필요)
- **낮/밤 주기**: 밤에는 시야 감소, 변이 동물 활동 증가

## 10. 적 / 생물
| 종류 | 행동 |
|---|---|
| 일반 동물 (사슴, 토끼) | 도망 — 사냥하면 식량 |
| 변이 동물 (늑대, 멧돼지) | 일정 거리 안에 들어오면 추격·공격 |
| 변이 대형 개체 | 고오염 지역의 보스급 |

- 에셋: Poly Pizza의 **애니메이션 포함 GLB** 우선 사용
- 변이 표현: 색상 변경(녹색 발광 머티리얼) + 크기 키우기

## 13. 프로젝트 폴더 구조
```
Project_zz/
├── project.godot
├── SConstruct       C++ 빌드 스크립트 (scons)
├── godot-cpp/       Godot C++ 바인딩 (git submodule)
├── src/             C++ 게임 코드 (GDExtension)
├── bin/             빌드된 .dll + project_zz.gdextension
├── docs/            기획 문서
├── assets/
│   ├── models/      GLB 모델 (Poly Pizza 등)
│   ├── textures/
│   └── audio/
├── scenes/
│   ├── main.tscn    테스트 맵
│   └── player/
└── CREDITS.md       에셋 출처/라이선스
```

### 코드 원칙
- 게임 로직은 **C++ 클래스**로 작성 → Godot 에디터에서 노드로 바로 사용 (예: `PlayerController`)
- 수치(속도, 감도 등)는 C++ 프로퍼티로 노출 → 에디터 인스펙터에서 조정
- C++ 수정 후 `scons`로 다시 빌드 → 에디터에 자동 반영 (reloadable)
